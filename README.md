# CTM Travel — сайт

Одностраничный сайт: туры по Европе + корпоративный travel и MICE.
Боевой домен — **corptravel.uz**, весь SEO настроен под него.

## Что где

| Файл | Зачем |
|---|---|
| `index.html` | Весь сайт целиком. Логотипы вшиты внутрь, отдельно ничего не нужно |
| `assets/og-cover.jpg` | Картинка превью для Telegram, WhatsApp, соцсетей (1200×630) |
| `assets/favicon.png` | Иконка сайта |
| `assets/logo-color.png` | Логотип для Schema.org и внешних сервисов |
| `robots.txt` | Правила для поисковых роботов |
| `sitemap.xml` | Карта сайта |
| `_headers` | Заголовки безопасности для Cloudflare Pages / Netlify |
| `nginx-security.conf` | Те же заголовки для nginx на VPS |
| `.nojekyll` | Отключает лишнюю обработку на GitHub Pages |

## Как выложить на GitHub Pages

1. github.com → **New** → имя `ctm-demo` → **Public** → Create.
2. **uploading an existing file** → перетащить всё содержимое этой папки → **Commit changes**.
3. **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты появится ссылка `https://<логин>.github.io/ctm-demo/`.

## ⚠️ Что сделать при переезде на corptravel.uz

Ровно два действия — оба помечены комментариями прямо в файлах:

1. **`index.html`**, строка 14 — удалить:
   ```html
   <meta name="robots" content="noindex, nofollow">
   ```
2. **`robots.txt`** — заменить содержимое на:
   ```
   User-agent: *
   Allow: /

   Sitemap: https://corptravel.uz/sitemap.xml
   ```

Пока эти строки на месте, демо не индексируется — так оно не попадёт в поиск
и не будет конкурировать с будущим основным сайтом.

После запуска: добавить сайт в Google Search Console и Яндекс.Вебмастер,
загрузить туда `sitemap.xml`.

## Что уже сделано по SEO

- Заголовок и описание под запрос «туры в Чехию из Ташкента»
- Canonical, hreflang, geo-метки (Ташкент)
- Open Graph и Twitter Card с готовой картинкой превью
- Разметка Schema.org: `TravelAgency` (адрес, телефон, услуги, страны), `WebSite`,
  `FAQPage` (6 вопросов), `ItemList` из 9 туров с ценами — строится автоматически из данных туров
- Семантическая вёрстка, alt у изображений, один H1, вложенность заголовков
- Блок «Частые вопросы» — под поисковые сниппеты и голосовой поиск

## Что сделано по безопасности

- **CSP** — запрещены сторонние скрипты, iframe, объекты и любые внешние подключения,
  кроме шрифтов Google. Даже если кто-то встроит чужой код — он не выполнится
- **Защита от кликджекинга** — `X-Frame-Options: DENY` и `frame-ancestors 'none'`
  (в `_headers` / `nginx-security.conf`)
- **Экранирование** — весь текст, попадающий в HTML, проходит через `esc()`, XSS невозможен
- **Форма**: скрытая ловушка для ботов + отсечка отправки быстрее 2 секунд,
  ограничение длины полей, очистка управляющих символов
- **Внешние ссылки** — `rel="noopener noreferrer"`, чужой сайт не получит доступ к вкладке
  и не увидит, откуда пришли
- **Referrer-Policy**, **nosniff**, **Permissions-Policy** (камера, микрофон, геолокация выключены)
- Никакой аналитики и сторонних трекеров — данные посетителей никуда не утекают

Проверить после запуска: [securityheaders.com](https://securityheaders.com)
и [Google Rich Results Test](https://search.google.com/test/rich-results).

## Как редактировать

Туры лежат в массиве `TOURS` в конце `index.html`. Добавить новый —
скопировать блок соседнего тура и заменить поля. Категории для фильтра — в `CATS`.
